# Third-party / vendored files

This repository is a **standalone prototype**. It is **not** part of, and does not
publish to, the Engage Design System repository.

The following files are **vendored copies** of the Effectory **Engage Design
System** (sourced from the `effectory-design-system` skill). They are included
only so the prototype runs on its own. They are owned and maintained in their own
separate project (`effectory-design-documentation`) — do not treat this repo as
their source of truth, and do not edit them here:

- `styles/tokens.css` — auto-generated DS tokens (regenerated upstream via `build-tokens.py`)
- `styles/foundation.css`
- `styles/components.css`
- `public/icons.js` — DS icon loader
- `public/assets/icons/*.svg` — DS icon set

Everything else under `src/`, `styles/app.css`, `index.html`, and the build config
is original to this prototype.
